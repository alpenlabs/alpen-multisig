Testing the Payout Administrator app

Three guides for a shared test round on regtest. Read them in this order.

  1. Build and run. Compile the coordinator and the desktop app, start your own regtest node, seed the chain and sign in.
  2. Feature guide. Every feature of the Payout Administrator UI, in the order you meet it, tied to the PRD requirement it implements, with what the app must refuse.
  3. Physical Ledger tests. Every flow the PRD requires on the device, as test cases with the expected screens and a result sheet (ledger-results.csv).

Default files for the round are in kit/: the host's and each tester's bitcoin.conf, the coordinator environment, launcher scripts and a roster template.
