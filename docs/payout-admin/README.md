# Payout Administrator test round

Open [index.html](index.html) in a browser (for example `open docs/payout-admin/index.html` on macOS or
`xdg-open docs/payout-admin/index.html` on Linux). It links the three guides:

- [setup.html](setup.html): build the binaries, start the regtest nodes and the coordinator, seed the chain, sign in.
- [guide.html](guide.html): every feature of the Payout Administrator UI against the PRD.
- [ledger-tests.html](ledger-tests.html): the tests to run on a physical Ledger, with [ledger-results.csv](ledger-results.csv).

Default files are in [kit/](kit/README.md).
